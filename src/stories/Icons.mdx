# Iconos MDI (Material Design Icons)

Droni-kit utiliza la librería **Material Design Icons (MDI)** para los iconos. El CDN se carga automáticamente en la aplicación.

## Instalación

Agrega el CDN de MDI en el `<head>` de tu archivo `index.html`:

```html
<link
  rel="stylesheet"
  href="https://cdn.jsdelivr.net/npm/@mdi/font@7.4.47/css/materialdesignicons.min.css"
/>
```

## Uso básico

Los iconos se utilizan como clases CSS con el prefijo `mdi`:

```html
<i class="mdi mdi-home"></i>
<i class="mdi mdi-account"></i>
<i class="mdi mdi-email"></i>
```

## Tamaños

Puedes controlar el tamaño de los iconos con clases de tamaño de fuente:

```html
<i class="mdi mdi-home mdi-18px"></i>
<i class="mdi mdi-home mdi-24px"></i>
<i class="mdi mdi-home mdi-36px"></i>
<i class="mdi mdi-home mdi-48px"></i>
```

O con clases de Tailwind CSS:

```html
<i class="mdi mdi-home text-sm"></i>
<i class="mdi mdi-home text-base"></i>
<i class="mdi mdi-home text-xl"></i>
<i class="mdi mdi-home text-4xl"></i>
```

## Uso en componentes Droni-kit

Los componentes como `DuiLabel` y `DuiNavbar` aceptan la prop `icon` con el nombre de clase MDI:

```vue
<DuiLabel title="Email" icon="mdi mdi-email" />
```

```vue
<DuiNavbar :items="[{ label: 'Inicio', to: '/', icon: 'mdi mdi-home' }]" />
```

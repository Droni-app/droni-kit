Droni-kit es el conjunto de componentes de UI del equipo de Droni.co. Está hecho para Vue 3 y Nuxt con Vite y se instala desde npm.

## Instalación

```bash
npm install @dronico/droni-kit
```

Importa la hoja de estilos una sola vez, en tu archivo principal (`main.ts`) o en `nuxt.config`. Incluye la tipografía **Inter** y los iconos **MDI**, así que no necesitas ningún `<link>` extra:

```javascript
import '@dronico/droni-kit/dist/droni-kit.css';
```

<details>
<summary>Nuxt 3</summary>

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  css: ['@dronico/droni-kit/dist/droni-kit.css'],
})
```

</details>

## Uso

```vue
<template>
  <DuiButton color="primary">Bienvenido a Droni-kit</DuiButton>
</template>

<script setup lang="ts">
import { DuiButton } from '@dronico/droni-kit'
</script>
```

## Dark mode

Agrega la clase `dark` a un ancestro (normalmente `<html>`). Todos los componentes tienen su versión dark, con glow neón sutil:

```js
document.documentElement.classList.toggle('dark')
```

En este catálogo puedes cambiar de tema con el selector de la barra superior.

# Design tokens

La paleta **Neon Noir** se inspira en el triángulo de la identidad Droni: violeta y magenta que se funden sobre un fondo navy, con un destello cian. Cada color es una variable CSS (`--dk-color-<rol>-<tono>`) que puedes sobrescribir en tu app. La guía de **Migración v2** explica cómo.

## Principios

| Principio | Cómo se aplica |
| --- | --- |
| **Serio primero** | Superficies sobrias, tipografía Inter, bordes de 1 px y sombras suaves. El color se reserva para la acción y el estado. |
| **Neón con intención** | El glow (`--dk-shadow-glow-*`) aparece sobre todo en dark mode: botones `solid`, elementos activos, LEDs de estado y el halo de los paneles. |
| **Focus cian** | Un único anillo de focus `accent` en toda la librería; se ve igual en light y en dark. |
| **Light y dark al mismo nivel** | Cada componente define los dos modos. El dark se activa con la clase `.dark` en un ancestro. |

## Otros tokens

| Variable | Uso |
| --- | --- |
| `--dk-font-sans` | Tipografía de los componentes (Inter por defecto). |
| `--dk-shadow-glow-{color}` | Halo neón de botones, switches y paginación en dark mode. |
| `--dk-shadow-elevated` / `--dk-shadow-elevated-dark` | Sombra de modales, drawers, dropdowns, tooltips y toasts. |
| `--dk-select-chevron` | Icono de flecha de `DuiSelect` (data URI SVG). |

## Uso en tu app

```css
/* después de importar @dronico/droni-kit/dist/droni-kit.css */
:root {
  --dk-color-primary-600: #2c47df;
  --dk-font-sans: "Geist", system-ui, sans-serif;
}
```
